## Тестовые параметры URL
| Параметр | Что делает |
|---|---|
| `?now=2026-10-18T21:00` | подменяет текущее время |
| `?theme=light` / `dark` | принудительная тема |
| `?pet=goose` / `mouse` / `capy` | принудительное животное |
| `?splash=0` | пропустить экран с лого |
| `?debug=1` | плашка с темой, животным и расписанием недели |
