# Pet Nap

Мини-приложение (PWA) для iPhone: фон по времени суток, лого при запуске (влетает слева, висит пока грузится, улетает вправо), свайп вверх показывает плюшевое животное снизу, свайп вниз прячет.

- Светлая тема 8:00–20:00, тёмная 20:00–8:00 (определяется при запуске).
- Животное выбирается автоматически на «день» (день начинается в 8:00, ночь с 20:00 до 8:00 — то же животное). Вчерашнее не повторяется, в неделе 3/2/2 (гусь, мышь, капибара), без схемы А/Б/А/Б.
- Работает офлайн (service worker), ставится на экран «Домой» через Safari.

## Публикация (GitHub Pages)
1. Залить содержимое папки в репозиторий `brawiy/pet-nap` (ветка `main`, файлы в корне).
2. GitHub → Settings → Pages → Source: `Deploy from a branch` → Branch: `main`, folder: `/ (root)` → Save.
3. Через 1–2 минуты сайт: https://brawiy.github.io/pet-nap/

## Установка на iPhone
Safari → открыть ссылку → кнопка «Поделиться» → «На экран “Домой”» → «Добавить».

## Тестовые параметры URL
| Параметр | Что делает |
|---|---|
| `?now=2026-10-18T21:00` | подменяет текущее время |
| `?theme=light` / `dark` | принудительная тема |
| `?pet=goose` / `mouse` / `capy` | принудительное животное |
| `?splash=0` | пропустить экран с лого |
| `?debug=1` | плашка с темой, животным и расписанием недели |

## Разработка
```
npm test       # автотесты логики (Node 18+)
npm start      # http://localhost:8080
```
Обновления: после `git push` открой приложение два раза (кэш обновляется в фоне).
Если меняешь список файлов — увеличь `CACHE` в `sw.js`.
